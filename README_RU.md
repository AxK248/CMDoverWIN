# CMDoverWIN (API v1.0)
Переосмысление Windows в виде легковесной и расширяемой CLI-системы. Никаких тяжелых графических интерфейсов и скрытых системных изменений — только чистый терминал на весь экран.

Проект разработан как независимый open-source каркас. Вы можете использовать готовое ядро, дополнять его своими аддонами или делать свои уникальные форки.

---

## 🛠️ Как это устроена архитектура системы
1. **`boot.bat`** — Первичный загрузчик. Настраивает окружение и подготавливает консоль.
2. **`menu.bat`** — Главная помощь в скрипте.
3. **`addons.bat`** — Изолированный менеджер дополнений (аддонов) с жестким контролем версий API.

---

## 🛑 ВАЖНОЕ ПРАВИЛО БЕЗОПАСНОСТИ ОКОН
В системе **намеренно не используется команда `call`** для запуска аддонов. Управление передается стороннему коду напрямую. 
* Если аддон написан криво, упал или выполнил слепой `exit` без возврата в систему — **окно консоли полностью закроется**.
* В этом случае вам придется открыть **Диспетчер задач (Task Manager)** и запустить Терминал (cmd). Автор ядра вас предупредил!

## 🔌 Инструкция для авторов аддонов (Дополнений)
Чтобы ваше дополнение успешно работало и отображалось в общем списке, оно должно находиться в собственной подпапке внутри директории `addons/` (например, `addons/my_utility/`).

Внутри папки обязаны находиться два файла: `info.txt` и `init.bat`.

### 1. Манифест дополнения (`info.txt`)
Файл конфигурации должен строго содержать следующие строки. **Важно** Если версия вашего API не совпадает с версией скрипта (сейчас это `1.0`), менеджер аддонов просто проигнорирует и скроет ваш мод из меню.

```text
Name: Название Вашего Дополнения
Author: Ваш_Ник
Version: 1.0
Code: уникальный_код_активации
API: 1.0
```

### 2. Скрипт запуска (`init.bat`)
Помните, что система делает `cd /d` прямо в папку вашего аддона перед стартом. Чтобы вернуться назад в меню `addons.bat`, вы **обязаны самостоятельно** прописать относительный путь на два уровня вверх(или смотря насколько глубоко засядет ваш bat с командой выхода):

```batch
@echo off
rem =======================================================
rem Код вашего дополнения пишется здесь
rem =======================================================
echo Привет, мир! Аддон успешно запущен по коду.
pause

echo Возврат в систему...
..\..\addons.bat
```

## ⚙️ Рекомендация по установке
Для максимального удобства рекомендуется добавить корневую папку проекта в системную переменную `PATH`. Это позволит вам мгновенно вызывать `boot`, `menu` или `addons` из абсолютно любого места и папки в Windows.
